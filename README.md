# Riverbank Dam Viewer — ตัวอย่างเขื่อนป้องกันตลิ่ง ชนิดตอกเสาเข็ม

เว็บแอปดูแบบจำลอง 3D ของเขื่อนป้องกันตลิ่งชนิดตอกเสาเข็ม (T3-01) ยาว 100 ม. คู่กับ Object Library และ BOQ ปร.4

> **ตัวอย่างสาธิต ห้ามใช้ก่อสร้าง** ขนาดชิ้นส่วนอ่านจากรูปขยายรูปตัดเขื่อนมาตรฐาน 1:50
> ค่าที่รูปไม่ได้ให้เป็นค่าสมมุติ (ติดป้าย "สมมุติ" ทุกตัว) รูปตัดสำรวจและความยาวเสาเข็มเป็นค่าสมมุติ และยังไม่ได้ตรวจเสถียรภาพ

## ใช้งาน

- **แบบจำลอง T3-01**: หมุน ซูม คลิกชิ้นส่วนเพื่อดูรายการ ปร.4 ปริมาตร ช่วง STA ระดับ และคลาส IFC
  ซ่อนหรือไฮไลต์ชิ้นส่วนจากรายการด้านซ้าย ตัดรูปตัดที่ STA ใดก็ได้ และคลิกบรรทัด BOQ เพื่อไฮไลต์ชิ้นที่ถูกนับในบรรทัดนั้น
- **Object Library**: 15 family ที่ใช้ประกอบเขื่อน ดูตัวอย่าง 3D พารามิเตอร์ ค่าที่ใช้ในแบบจำลอง และที่มาของค่า
  (อ่านจากแบบ / รายการประกอบแบบ / สมมุติ) พร้อมรายการ family ที่วางแผนไว้สำหรับเขื่อนชนิดอื่น

## เปิดในเครื่อง

```bash
python3 -m http.server 8765
```

แล้วเปิด http://localhost:8765 (เปิดไฟล์ `index.html` ตรงๆ ไม่ได้ เพราะเบราว์เซอร์ไม่ให้โหลดข้อมูลจาก `file://`)

## ไฟล์

| ไฟล์ | คืออะไร |
|---|---|
| `data/t3_01.glb` | แบบจำลอง glTF 2.0 ส่งออกจาก IngeTrazo 1 node ต่อชิ้น ข้อมูลชิ้นอยู่ใน node `extras` (ปริมาตร รายการ ปร.4 ช่วง STA พิกัด) |
| `data/library.json` | แค็ตตาล็อก family พารามิเตอร์ ที่มาของค่า และบรรทัด BOQ |
| `assets/library/` | ภาพตัวอย่าง family จากแบบจำลอง |
| `vendor/three/` | three.js 0.186.0 (MIT License) |

ตัวเลขทุกตัวในหน้าเว็บมาจากไฟล์ข้อมูลเหล่านี้ ซึ่งคำนวณด้วยสคริปต์จากแบบจำลอง หน้าเว็บแค่จัดรูปแบบและรวมยอด
